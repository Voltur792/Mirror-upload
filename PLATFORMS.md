# Поддержка платформ

Linux и macOS — **экспериментальные**. Проверки Python и автоматические тесты не заменяют проверку графики, звука и работы внутри Astra на реальной ОС. Windows сохраняет прежние возможности.

Официальные хосты Astra сейчас доступны для Windows x64 и Linux x64. Код подготовлен также под macOS, но официального хоста Astra для Mac и ARM пока нет: установить и полноценно проверить плагин там внутри Astra нельзя. См. [платформы Astra](https://github.com/mihailinl/AstraPlugins/blob/master/docs/en/1-orientation/platforms.md).

На Linux и macOS экспериментально доступны каталог, загрузка и проверка пакетов моделей, установка из локального ZIP и обнаружение файлов моделей. Среды исполнения и библиотеки устанавливаются отдельно.

**Быстрая настройка, установщики Python/WebView2, Windows-сборки Node/uv, ярлык завершения и изменение переменных Windows остаются только для Windows x64.** На других ОС эти действия отключены; Windows-установщики не запускаются. При отсутствии подходящего движка в Astra наличие файлов модели не означает возможность её запуска.

В релизе два варианта: `windows-x64.astraplugin` содержит прежний автономный Windows-запуск без отдельно установленного Python; `noarch.astraplugin` — переносимый Python-вариант для Linux и подготовки macOS (нужен Python 3.11+ и зависимости). Это отдельные варианты, не устанавливайте оба одновременно. Переносимый вариант не включает Windows-установщики и не заменяет системный менеджер пакетов.

Linux: каталог данных `$XDG_DATA_HOME/astra` (по умолчанию `~/.local/share/astra`), конфигурация `$XDG_CONFIG_HOME/astra/component-mirror` (по умолчанию `~/.config/astra/component-mirror`). macOS: каталог данных `~/Library/Application Support/com.astra.astra`, настройки плагина в его подпапке `component-mirror`. Для переносной или нестандартной установки укажите фактическую папку данных в настройках плагина. Пути Windows сохранены.
