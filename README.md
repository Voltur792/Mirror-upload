# Mirror-upload

Плагин для Astra, который скачивает локальные модели и зависимости через зеркало Яндекс Диска. Помогает настроить Astra, когда обычные источники загрузки недоступны. Поддерживается **Windows x64**.

## Возможности

- **Быстрая настройка Астры** — загрузка и установка подготовленного набора зависимостей одной кнопкой.
- Отдельная установка моделей во вкладке **«Компоненты»** и импорт подготовленного ZIP-пакета с компьютера.
- Автоматическое подключение зеркала, отображение прогресса и отмена загрузки.
- Определение папок текущего пользователя, включая пути с русскими буквами. Для переносной Astra можно указать расположение вручную.
- Одноразовый ярлык на рабочем столе для завершения настройки и возможность вернуть изменённые настройки Windows.

Сам Mirror-upload запускается со встроенным Python. **Другие плагины он не устанавливает** — только необходимые для них компоненты.

## Что установит быстрая настройка

| Компонент | Для чего нужен |
| --- | --- |
| Python 3.13, если подходящего Python ещё нет | Запуск Python-плагинов и их библиотек. |
| Переносной Node.js LTS и uv | Запуск Node-плагинов и подготовка окружений Python. |
| Локальная библиотека Python-пакетов | Установка зависимостей поддерживаемых плагинов без обращения к PyPI. |
| Supertonic 3 и Vox Astra Neutral | Локальное озвучивание ответов Astra. Vox активируется отдельно в Astra. |
| Whisper large-v3-turbo и вариант q5_0 | Локальное распознавание речи в Astra. |
| Embeddings m2v-qwen3-small | Локальная обработка и поиск по текстам. |
| Vosk, faster-whisper tiny/base/small и библиотеки локальных голосов | Голосовой набор и локальные голосовые функции Discord-плагина. |
| FFmpeg | Обработка аудио для голосовых функций. |
| EasyVK | Музыкальные функции VK в Astra Music. |
| Microsoft WebView2, если он отсутствует | Встроенные окна входа и веб-интерфейсы плагинов. |
| CLI Codex, Gemini и Claude | Работа соответствующих провайдеров; вход в аккаунты выполняется отдельно. |

Подготовленный набор охватывает зависимости официального каталога и выпущенных плагинов Voltur792: Discord, Astra Music, Таймер паузы, Голосовой набор, Автоассистент, Морской бой, Детектив, Умный дом и Управление браузером. В версии 0.5.4 это **22 разных плагина**. Зависимости будущих версий могут отличаться.

## Как использовать

1. Скачайте **`component-mirror-0.5.4-windows-x64.astraplugin`** из [Releases](https://github.com/Voltur792/Mirror-upload/releases/latest) и импортируйте файл в Astra.
2. Откройте вкладку **Mirror-upload**, нажмите **«Быстрая настройка Астры»** и дождитесь завершения. Для загрузки нужны свободное место и доступ к Яндекс Диску.
3. Закройте Astra и **один раз** запустите ярлык **«Mirror-upload - Завершить настройку»** на рабочем столе. После успешного запуска Astra ярлык удалится сам. При ошибке он останется, чтобы можно было повторить запуск.
4. Дальше запускайте Astra обычным способом. Выберите нужные модели в её настройках и войдите в используемые сервисы под своим аккаунтом.

Для установки одной модели откройте **«Компоненты»** и выберите нужный комплект. Загрузка начинается только по вашей команде.

Папка данных определяется для пользователя, у которого установлен плагин. Для переносной версии укажите в настройках плагина абсолютный путь к папке `data`, содержащей `models`, и путь к `Astra.exe`.

## После настройки

Быстрая настройка сохраняет пути к Python/Node.js и локальный источник библиотек в переменных **текущего пользователя Windows**. Это действует также на другие программы Python: pip и uv будут искать пакеты в подготовленной локальной библиотеке. Для установки других пакетов из интернета нажмите **«Настройки → Вернуть настройки Windows»**, затем перезапустите программы. Установленные модели и компоненты сохранятся.

Временные архивы и установщики удаляются после успешной настройки. Рабочие среды, библиотеки и модели остаются — они нужны для дальнейшей работы. Ярлык не занимает оперативную память.

Существующие отличающиеся файлы и окружения не перезаписываются. Статус **«Файлы на месте»** означает наличие комплекта; выбор модели и запуск её движка выполняются в Astra. Учётные записи, активация Vox и расширение браузера настраиваются отдельно. Облачные сервисы требуют собственного доступа к интернету.
